# Site ABF Ferramentaria e Usinagem de Precisão

Site estático de 3 páginas: `index.html`, `maquinas.html`, `contato.html`, mais `style.css` e `script.js`. Sem build, sem dependências. Todos os links são relativos, então funcionam em subpasta do GitHub Pages.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub e envie todos os arquivos desta pasta para a raiz (incluindo `.nojekyll` opcional).
2. No repositório: Settings > Pages > Source: "Deploy from a branch" > branch `main`, pasta `/ (root)` > Save.
3. Em alguns minutos o site fica em `https://SEU-USUARIO.github.io/NOME-DO-REPO/`.

## Formulário

1. Crie um formulário em formspree.io com o e-mail abfusinagem@gmail.com.
2. Em `contato.html`, troque `SEU_ID_AQUI` pelo ID (o trecho depois de `/f/`).
